How to Use Kleson Finance

  1. Add your income and expenses with correct dates.
  2. Set a monthly budget to monitor spending limits.
  3. Use transaction filters to analyze a particular month or category.
  4. Check expense progress bars to see which category consumes your budget.
  5. Export CSV or print report for project documentation.

Disclaimer: This is a frontend academic prototype. It stores data locally in the user’s browser and does not connect to a bank or external server.
